# 개인 프로필 페이지 - 요구사항 정의서

## 1. 프로젝트 개요
- **프로젝트명**: 개인 프로필 페이지 (Personal Profile Page)
- **목적**: 자기소개, 경력/스킬, 포트폴리오, 연락처를 한 페이지에 담은 개인 웹사이트 제작
- **기술 스택**: HTML5, CSS3, Vanilla JavaScript (프레임워크 없음)
- **대상 폴더**: `frontend/` (소스 코드), `docs/` (기획 문서), `backend/` (추후 연락처 폼 등 서버 기능 필요 시 사용)

## 2. 페이지 구성 (섹션 목록)
| 순서 | 섹션 | 설명 |
|---|---|---|
| 1 | Header / Navigation | 로고 또는 이름, 섹션 이동 메뉴, 다크모드 토글 |
| 2 | Hero (자기소개) | 프로필 사진, 이름, 한 줄 소개, 타이핑 애니메이션(직무/타이틀), SNS 링크 |
| 3 | About | 상세 소개, 간단한 이력 요약 |
| 4 | Skills | 기술 스택을 아이콘 또는 프로그레스바로 표시 |
| 5 | Projects / Portfolio | 프로젝트 카드(썸네일, 제목, 설명, 링크), 필터 기능(선택) |
| 6 | Experience / Education | 타임라인 형태의 경력/학력 |
| 7 | Contact | 연락처 폼(이름, 이메일, 메시지) + 유효성 검사, 이메일/SNS 아이콘 |
| 8 | Footer | 저작권 정보, 맨 위로 이동 버튼 |

## 3. 기능 요구사항 (JavaScript)
- [ ] 모바일 햄버거 메뉴 열기/닫기
- [ ] 네비게이션 클릭 시 부드러운 스크롤(smooth scroll)
- [ ] 스크롤 위치에 따라 현재 섹션 메뉴 하이라이트
- [ ] 다크모드 / 라이트모드 토글 (localStorage에 상태 저장)
- [ ] Hero 영역 타이핑 효과 애니메이션
- [ ] 스크롤 시 요소 페이드인 애니메이션 (IntersectionObserver)
- [ ] 연락처 폼 입력값 유효성 검사 (필수 입력, 이메일 형식)
- [ ] 프로젝트 필터링(카테고리별 보기) - 선택 기능
- [ ] 맨 위로 이동 버튼 표시/스크롤 이동

## 4. 비기능 요구사항
- 반응형 디자인: 모바일(~480px) / 태블릿(~768px) / 데스크톱(1024px~) 대응
- 시맨틱 HTML 태그 사용 (header, nav, main, section, footer 등)
- 접근성: alt 텍스트, 적절한 명도 대비, 키보드 포커스 스타일
- 성능: 이미지 최적화, 불필요한 외부 라이브러리 최소화
- 브라우저 호환성: 최신 Chrome, Edge, Firefox, Safari

## 5. 향후 확장 (선택)
- 연락처 폼 실제 전송 기능 → `backend/` 폴더에 간단한 서버(Node.js 등) 연동
- 블로그/글 목록 섹션 추가
- 다국어(한/영) 지원
