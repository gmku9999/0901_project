# 개발 체크리스트

## 준비 단계
- [ ] 콘텐츠 원고 확정 (자기소개, 프로젝트 설명 등)
- [ ] 프로필 사진 및 프로젝트 썸네일 이미지 준비
- [ ] 색상/폰트 등 디자인 가이드 확정

## HTML
- [ ] 시맨틱 태그로 전체 구조 작성 (header/nav/main/section/footer)
- [ ] 각 섹션에 id 부여 (네비게이션 앵커용)
- [ ] 이미지 alt 속성 작성
- [ ] meta 태그 작성 (title, description, viewport, favicon)

## CSS
- [ ] reset/기본 스타일 작성
- [ ] CSS 변수로 색상/폰트 정의 (라이트/다크 모드 대응)
- [ ] 섹션별 스타일 작성
- [ ] 반응형 미디어 쿼리 적용 및 실기기/브라우저 테스트

## JavaScript
- [ ] 모바일 메뉴 토글 구현
- [ ] 스무스 스크롤 및 스크롤 하이라이트 구현
- [ ] 다크모드 토글 + localStorage 저장 구현
- [ ] 타이핑 애니메이션 구현
- [ ] 스크롤 페이드인 애니메이션 구현 (IntersectionObserver)
- [ ] 연락처 폼 유효성 검사 구현

## 품질/배포
- [ ] 크로스 브라우저 확인 (Chrome/Edge/Firefox/Safari)
- [ ] 반응형 확인 (모바일/태블릿/데스크톱)
- [ ] 접근성 점검 (키보드 탐색, 명도 대비)
- [ ] 이미지/리소스 최적화
- [ ] 배포 (GitHub Pages, Netlify, Vercel 등)
